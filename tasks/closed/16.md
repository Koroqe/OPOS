# v0.7.1 — fix console dept-badge white-on-white rendering

## Goal

Patch fix for the console UI: `ui/static/console.css` line 129 sets `color: white` for all `.dept[data-dept]` badges, but the per-dept background-color rules only cover the stale pre-v0.5.1 dept names. 5 of 7 starter depts (finance, people, legal, commercial, pr) fall through → white text on white background → invisible. Discovered by user during live console review of v0.7.0. Add the 5 missing dept mappings + a fallback `background: var(--fg-dim)` so future user-created depts (via `/design-department`) also get a sensible default rather than invisible.
