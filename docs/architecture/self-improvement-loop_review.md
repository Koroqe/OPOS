# Architecture review — self-improvement-loop (v0.9.0)

**Verdict: APPROVED WITH CONDITIONS** (architect agent, 2026-08-19; full review retained in the development session).

The module split (`auto-sync` vs `sync-from-core`; `review-history` → `propose-to-core` one-way), the ledger-vs-run-record separation, and the ground-truth-driven CORE/STARTER resolution were assessed sound; no circular dependencies or invalidating boundary violations.

## Blocking conditions (all incorporated during implementation)

- **C1** — `propose-to-core` run-record routing: ship `scheduled-runs/.gitkeep` AND state in SKILL.md that a *sub-invocation* (from a scheduled `review-history` run) writes no separate run record — the parent's scheduled-run entry plus the LEDGER line are the record; the prelude routing check applies to direct invocations only. → U5.
- **C2** — Classification version-skew: fetch `copier.yml` at the consumer's pinned `_commit` (`?ref=<_commit>`) for `_skip_if_exists` classification; probe upstream existence at default-branch HEAD; disagreement between the two → human-draft path. Prevents ever locally editing a CORE file. → U5/U7.
- **C3** — Deterministic redaction pre-gate BEFORE either agent pass, hard-fail: `grep -F -i -f <blocklist-file>` across the full bundle (diff, PR body, **PR title**, branch name, commit message, diff file paths) plus a secret-shaped regex sweep (`gh[pousr]_[A-Za-z0-9]{36}`, `AKIA[0-9A-Z]{16}`, `xox[baprs]-`, `-----BEGIN [A-Z ]*PRIVATE KEY-----`, `postgres(ql)?://…:…@`, `[?&](api_?key|token|password)=`). PR title joins the reviewed bundle; slug derives only from the sanitized upstream path. → U4/U5.
- **C4** — CHANGELOG auto-resolution as a mechanical predicate: insert immediately before the first `^## \[` line (none → escalate); every `.rej` hunk has zero `-` lines and `+` lines are only a version block (`^## \[x\.y\.z\]…`) and/or link-ref lines (`^\[x\.y\.z\]: https://`); verify with the canonical awk from `release-from-changelog` **plus** the negative assertion that no `^## [0-9]{4}-` day heading ends up below the first `^## \[`. → U2.
- **C5** — `{% raw %}` discipline for all `.jinja` edits (U3/U8/U9); U11 scaffold check asserts no residual `{{`/`{%` in rendered `README.md`/`RISKS.md`/`CLAUDE.md`; same escaping rule in `propose-to-core`'s drafting step for `.jinja` targets and in MAINTAINER's incoming-PR checklist.
- **C6** — `LEDGER.md` schema defined once in `proposals/README.md`; `propose-to-core` appends rows only; `review-history` mutates only the `outcome` column of existing rows. → U5/U6/U7.
